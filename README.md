# Concrete Crack Images for Classification

## Overview

Concrete Crack Images for Classification is a task-specific package derived from the Mendeley Data dataset.

- Task: classification
- Images: 40000
- Annotations: 40000
- Classes: 2 (cracked, non-cracked)
- Annotation format: image-level labels in class folders

This package contains 40,000 227x227 RGB concrete surface patches (20,000 cracked / `Positive` and 20,000 non-cracked / `Negative`) generated from 458 full-resolution (4032x3024) photographs of concrete building walls and floors on the METU campus in Ankara, Turkey, captured at approximately 1 m distance without random rotation or flipping augmentation following the patch-extraction method of Zhang et al. (2016).
